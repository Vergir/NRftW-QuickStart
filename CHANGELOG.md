# Changelog

## 1.0.0

First release.

* Skips the logo video when the game starts.
* Skips the main menu: presses Continue once per launch, as soon as it is available (last character, last realm).
* Hold Left Shift (configurable) while the game loads to stay in the main menu.
* Options > Gameplay: Skip Videos on Launch, Skip Main Menu on Launch, Hold to Stay in Main Menu (click and press any key).
